# @whyself/ttds

Talk to DeepSeek（TTDS）是面向 DeepSeek Harness（DSH）的实时语音交互插件包，提供低延迟、低幻觉、富有交流感的语音对话体验，并通过工具调用衔接 DSH 公开接口，支持语音模型查看 DSH 内容与协助用户操作 DSH。安装后通过 `cordis.patch.yml` 将插件挂载到用户 DSH profile 中。

## 模型体验

无，因为当前初始化骨架仅挂载宿主插件生命周期入口，尚未向模型请求注入系统提示、工具定义或会话记录。

## 已知限制与延期工作

- **尚处于骨架阶段**：实时语音会话通道、DSH 状态读取与操作工具集及客户端语音界面尚待实现。
